# 示例：一次完整的五步零焦虑微课（合成示范）

> **用户提问**：老师，英文题里同时给了股票收益、大盘收益和无风险利率，让我算超额收益，我每次看到一堆百分比就晕，怎么分清楚？

---

### 第 1 步：剥离外壳，一句话讲透底层常识
把题干里的公司名和金融包装全删掉，**单只股票超额收益**考的其实只有一个日常常识：**“你冒着风险买这只股票赚到的钱，比把钱稳稳存进无风险国债多赚（或少赚）了多少？”**

### 第 2 步：中文精讲 + 强绑定英文原词
- 股票自身收益率：**Stock Return** ($R_i$)
- 无风险利率：**Risk-Free Rate** ($R_f$，可以理解成几乎不会违约的短期国债利息)
- 单只股票超额收益：**Individual-Stock Excess Return** ($R_i - R_f$)

核心逻辑非常直白：拿你买股票实际赚的 **Stock Return**，减去啥风险不冒也能拿到的 **Risk-Free Rate**，剩下的差额就是你为“承担风险”多拿到的回报。

### 第 3 步：极简数字算例 + 干扰项排雷
假设某天题目给了 3 个数字：
- 股票收益 **Stock Return** = `-0.60%`
- 大盘收益 **Market Return** = `-0.80%`
- 无风险利率 **Risk-Free Rate** = `+0.04%`

**一步算出结果**：
- $\text{Excess Return} = R_i - R_f = (-0.60\%) - (+0.04\%) = -0.64\%$

⚠️ **干扰项排雷（Distractor Trap）**：
1. 题目里的 **Market Return (`-0.80%`)** 是纯干扰项！算“相对于无风险利率的超额收益”时直接忽略它（只有题目明确问 *relative to the market* 才减大盘）。
2. **注意负号方向**：股票本身已经亏了 `0.60%`，而无风险存款还能赚 `+0.04%`，所以你比稳健存款足足跑输了 **`-0.64%`**，不是 `-0.56%`。

### 第 4 步：考场直接变现产物
- **小抄公式**：`Excess Return = Stock Return − Risk-Free Rate`（默认比 $R_f$，别被 Market Return 带偏！）
- **英文简答一句模板**：*"Individual-stock excess return measures the return above the risk-free rate ($R_i - R_f$), isolating the reward for bearing risk."*

### 第 5 步：一秒随堂小题
如果某天一只股票涨了 `+2.00%`，大盘涨了 `+1.50%`，无风险利率是 `+0.10%`，这只股票的 **excess return** 是多少？（直接回一个百分比数字即可！）
